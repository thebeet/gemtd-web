# Draft — Yjs 协作 Markdown Demo

一个 Vue 3 + TypeScript 编写的实时协作 Markdown 编辑器。访问同一 `?room=` 链接的用户会共享同一篇文档。

## 运行

```bash
npm install
npm start
```

打开 `http://localhost:5173`。把“分享文档”生成的链接发给其他人；本地局域网测试时请用机器的局域网 IP 替换链接中的 `localhost`。

画板页面位于 `http://localhost:5173/paint`。它同样使用 `?room=` 区分协作房间。

体素工坊页面位于 `http://localhost:5173/board`。点击 21×21 的正交网格可堆叠方块；切换删除模式后，移除中间方块会让同列上方方块自然下落。

宝石 TD 布阵页位于 `http://localhost:5173/game`。它使用与 Dota 2 GemTD 相同规模的 37×37 方形网格，包含起点、终点和 5 个经过点，并提供七种宝石塔及岩石障碍物。

每波进入建造阶段后，玩家在地图上放置 5 个随机颜色和品质的候选塔，再选择保留单塔、相同塔升阶或可用的配方合成结果；未保留的候选塔会变成岩石。玩家等级决定五档品质概率。

指挥官等级由击杀经验决定，并在同一房间内共享：Lv.2 至 Lv.5 的累计经验分别为 250、650、1200、1900。第 1–9 波每只怪提供 5 XP；其后每十波间隔依次为 10、15、20、25 XP；第 10、20、30、40、50 波 Boss 每只提供 300 XP。这些数值参照公开的 GemTD Dota 2 脚本实现；原版的精英怪额外经验机制尚未在本 demo 的刷怪表中启用。

结算建造后，点击“开始战斗”会进入服务端权威模拟：怪物移动、塔目标选择、弹道飞行时间、命中扣血和波次结算都在 `server/game.ts` 中以 20Hz 固定 Tick 推进。前端通过同一 WebSocket 接收状态快照并插值渲染怪物、血条、弹道和命中特效；新加入同一 `?room=` 的用户会直接收到当前战斗快照。战斗中地图布局锁定。

`npm start` 同时启动：

- Vite 前端：`5173`
- WebSocket 服务：`1234`（Yjs 协作路径与 `/game-sync` 战斗同步路径）

## 部署提示

前端构建后，用 `npm run server` 启动同步服务，并让反向代理把 WebSocket 路径转发到该服务。若同步服务不与前端同域，请在构建时设置 `VITE_YJS_URL`，例如：

```bash
VITE_YJS_URL=wss://collab.example.com npm run build
```

此 demo 的同步状态仅保存在服务内存；服务重启后文档会清空。生产环境可为 y-websocket 接入持久化数据库，并添加鉴权。
